### About

I've been a dreamer all my life. Code was the first thing that let me see my ideas, not just imagine them — and that hasn't changed. I'm still chasing the same feeling: watching something in my head become something real.

Some days it's a real project. Some days it's just an idea I had to try. Both count.

Most of what I build is private client work, so this page is the index — the write-ups live on [**fridaydeveloper.com**](https://fridaydeveloper.com).

### Work

| Project | What it is | Built with |
|---|---|---|
| [**Atlas**](https://fridaydeveloper.com/work/atlas) | The system a fibre broadband operator runs its day on, plus the phone app its crews use out on site. | PHP 8.4 · MySQL · raw PDO · Tabler · Leaflet · ApexCharts · websockets |
| [**AirFellow**](https://fridaydeveloper.com/work/airfellow) | A social app for passengers on the same plane — chat, games, a cabin radar. No internet involved. | React Native 0.81 · Expo 54 · TypeScript · Bluetooth LE · Reanimated · noble crypto |
| [**Foral**](https://fridaydeveloper.com/work/foral) | A private register of land and property — plots, paperwork, sales and deadlines, all on a map. | Next.js 16 · React 19 · PostgreSQL 17 + PostGIS · Drizzle · MapLibre GL |
| [**Reeve**](https://fridaydeveloper.com/work/reeve) | A desktop app for running several Claude CLI sessions across projects at once, in one window. | Electron 43 · React 19 · node-pty + xterm.js · node:sqlite · dockview |
